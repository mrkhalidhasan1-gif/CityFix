# CityFix

Crowdsourced Civic Issue Reporting System.

## Features

- Citizen registration and login
- Civic issue reporting with photo upload
- Automatic issue category suggestion
- User dashboard with report photos and status timeline
- Admin dashboard with filters and issue management
- Admin status updates with comments for citizens
- Public issue list and issue details
- Current-month civic statistics
- REST APIs with Node.js and Express.js

## Stack

HTML, CSS, JavaScript, Node.js, Express.js, MongoDB.

## Run

1. Install Node.js and MongoDB.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Create a `.env` file using `.env.example`.
5. Start MongoDB.
6. Run `node server.js`.
7. Open `http://localhost:5001`.

Do NOT use VS Code Live Server.

## Admin

Admin credentials are configured through `.env`.

Do not commit your `.env` file to GitHub.
